# Daumenkino Studio

Eine einzelne HTML-Datei zum Zeichnen von Daumenkinos – mit Live-Vorschau, Video- und GIF-Import und druckfertigen Bögen für den **Canon SELPHY** (Postkarte 100 × 148 mm, Kreditkarte 54 × 86 mm, Quadrat-Sticker 54 × 54 mm, L-Format) und A4.

## Starten

`index.html` im Browser öffnen (Chrome, Edge, Firefox oder Safari). Keine Installation nötig.

## Funktionen

- Zeichnen mit Feder, Pinsel, Marker, Radierer, Formen, Füllen und Pipette; Zwiebelhaut, Haltezeiten, Rückgängig
- Live-Vorschau mit Blätter-Effekt (Schleife, Ping-Pong, Einmal; 1–30 fps)
- Import von Videos (MP4/WebM) und GIFs: Zeitbereich, Bildrate, Ausschnitt, Looks (Graustufen, Poster, Tinte, Strichzeichnung)
- Streifen-Modus: Streifenbreite frei wählbar (z. B. 2 cm), viele Bilder pro SELPHY-Blatt
- Randlos einpassen (zuschneiden oder strecken) oder ganz zeigen
- Druckbögen mit 300 dpi als JPG/PNG, einzeln oder als ZIP; Schnittlinien, Sicherheitsrand, Griffseiten

## Drucken mit der SELPHY

Blätter speichern, in der SELPHY-App das passende Papier wählen, **randlos** drucken und Datumsaufdruck sowie automatische Bildkorrektur ausschalten. Bleiben weiße Kanten, den Sicherheitsrand verkleinern; wird etwas abgeschnitten, vergrößern.

Projekte werden lokal im Browser gespeichert (IndexedDB).
